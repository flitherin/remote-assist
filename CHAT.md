# Текстовый чат

Это экспериментальный TCP-чат, без передачи экрана и удалённого управления. Не имеет TLS и аутентификации: сообщения доступны для чтения/подмены в недоверенной сети. Используйте доверенную локальную сеть или VPN. Приложение не изменяет брандмауэр и не устанавливает автозапуск.

1. На принимающей стороне запустите assist_server.exe. Для проверки на одном ПК оставьте 127.0.0.1. Для двух ПК укажите локальный IPv4 сетевого интерфейса принимающей машины. Нажмите «Начать / запросить чат».
2. Запустите assist_client.exe, укажите IPv4 принимающей машины и нажмите ту же кнопку. Используется TCP-порт 45873.
3. На сервере появится окно запроса с IP клиента. «Да» принимает, «Нет» отклоняет. Личность участника не проверяется; IP не подтверждает личность. До принятия сообщения чата не принимаются.
4. В активном сеансе доступно поле сообщения и кнопка «Отправить». Кнопка «Завершить сеанс» на любой стороне закрывает соединение. Закрытие окна тоже прекращает сеанс.
5. После завершения на сервере снова нажмите кнопку начала для нового сеанса.

На сервере разрешён один участник за раз. Сообщения ограничены 1500 символами, журнал очищается после 60000 символов. Ожидание подключения/ответа ограничено 30 секундами. Брандмауэр Windows может потребовать разрешение входящего соединения для выбранной сети.

Проверка перед использованием на Windows: принятие и отклонение запроса, сообщения на русском в обе стороны, завершение с обеих сторон, закрытие окна, потеря связи, повторное соединение, DPI 100/150/200%. Эти сценарии в Windows ещё не выполнены; здесь подтверждена только кросс-компиляция и структура EXE.
