# Remote Assist — единое приложение

Версия с файлами и звуком: dist/RemoteAssist-files-audio-win64.zip, один файл RemoteAssist.exe для обеих сторон. Старые client/server EXE и архивы относятся к предыдущему протоколу и несовместимы с новой версией.

## Подключение
1. На принимающем компьютере выберите «Владелец · принять подключение», укажите локальный IPv4 и порт, нажмите «Начать сеанс».
2. На другом компьютере выберите «Оператор · подключиться», укажите IPv4 владельца и тот же порт.
3. Владелец подтверждает запрос. Показ экрана требует отдельного согласия кнопкой «Разрешить показ экрана».
4. Чат и просмотр находятся в одном окне. Enter отправляет сообщение. Завершение закрывает соединение и очищает экран. После отказа или отключения сервер продолжает ожидание.

Для проверки на одном компьютере запустите два экземпляра и используйте 127.0.0.1. В этом случае просмотр попадает в захват того же рабочего стола, вызывая повторение картинки. Для проверки качества используйте два компьютера.

## Изменения
Кадр 1280×720 вместо 320×180 (в 16 раз больше пикселей); пропорции монитора сохраняются с чёрными полями. Используется системное сжатие XPRESS Huffman без потерь, сглаживание при масштабировании, до 15 кадров в секунду при свободной очереди. При медленной сети частота ниже; новые кадры не добавляются в занятую очередь. Остановка передаёт сигнал очистки после уже поставленных в очередь данных.

Окно изменяет размер и поддерживает DPI. Роль и порт выбираются до подключения. Сохраняются последние сообщения при переполнении истории.

## Ограничения
Встроенное управление мышью и клавиатурой доступно после отдельного согласия владельца. Все действия выполняются в одном приложении. Транспорт без шифрования и проверки личности; используйте доверенную сеть/VPN. Нет выбора монитора, автоматических обновлений и цифровой подписи. Разрешение фиксировано 1280×720, для текста на 4K-мониторах потребуется дальнейшее повышение.

## Передача файлов и звука (CHAT/4)
Обе стороны должны обновиться до версии CHAT/4. После подключения нажмите «Отправить файл…». Передача доступна в обе стороны, по одному исходящему и входящему файлу одновременно, до 16 ГиБ. Получатель подтверждает запрос и выбирает новое имя. Существующие файлы не перезаписываются, полученный файл автоматически не запускается. Повторное нажатие «Отправить файл…» позволяет отменить отправку.

Данные записываются во временный файл рядом с назначением; после полного приёма он переименовывается. При отмене, ошибке, отключении или пяти минутах бездействия незавершённый файл удаляется. После аварийного завершения приложения файл .part может потребовать ручного удаления. Докачка не поддерживается.

Владелец нажимает «Передавать звук», чтобы транслировать системный звук текущего устройства вывода Windows оператору. «Остановить звук» и завершение сеанса отключают трансляцию. Микрофон не захватывается. Звук включается отдельно от показа экрана. На одном компьютере трансляция запрещена для предотвращения звуковой петли.

Захват через WASAPI loopback, передача PCM 16 бит с частотой и количеством каналов устройства владельца. Очередь воспроизведения ограничена; при занятом соединении аудиопакеты пропускаются. Экран, файлы и звук используют одно TCP-соединение, поэтому медленная сеть может вызывать паузы. При смене устройства вывода включите звук заново.

Проверены Release-сборка MSVC x64 и автоматические тесты двоичных/пустых файлов, некорректных данных, старых идентификаторов, защиты от перезаписи и удаления незавершённых файлов. Воспроизведение звука и полный обмен между двумя ПК требуют проверки на реальных устройствах.

## Сборка и проверка
PowerShell 7: ./build_windows.ps1. Нужны Visual Studio Build Tools с C++, Windows SDK и CMake. Результат: build-windows/Release/assist_app.exe. Сборка MSVC x64 Release и проверка форматирования изменений прошли; предупреждения WSAAsyncSelect остаются. Интерактивный обмен между двумя компьютерами, производительность и масштабирование интерфейса ещё не проверены.

## Управление с разрешения владельца
Новый протокол CHAT/4: обе стороны должны обновить приложение. После принятия подключения владелец включает показ экрана, затем нажимает «Разрешить управление» и подтверждает отдельный диалог. Оператор нажимает на изображение: доступны движение, три кнопки мыши, перетаскивание, колесо и клавиатура. Передаются физические клавиши; раскладку определяет принимающая Windows.

Отзыв: «Запретить управление», Ctrl+Alt+F12, остановка показа или завершение соединения. При новом соединении требуется новое согласие. Если аварийная комбинация занята, управление не включается. При потере фокуса оператором отпускаются удерживаемые клавиши и кнопки; разрешение при этом сохраняется. F12 удалённо не передаётся.

Управление основным монитором и обычными приложениями текущего пользователя. UAC, защищённый рабочий стол, Ctrl+Alt+Delete и приложения с более высокими правами не поддерживаются. Частота экрана остаётся до 15 кадров в секунду. Передача без шифрования и аутентификации: только доверенная сеть/VPN. Номер разрешения отклоняет команды прошлого разрешения, но не является средством сетевой аутентификации.

Проверена MSVC Release-сборка и автоматический тест запрета ввода без согласия, неверного номера разрешения, некорректных команд, отзыва и освобождения удерживаемых клавиш/кнопок. Тест подменяет системный ввод, не управляет реальным рабочим столом. Полный пользовательский сценарий между двумя ПК ещё не проверен.

Управление при подключении к тому же ПК запрещено: loopback и собственные IPv4 обнаруживаются локально. Это предотвращает петлю одного системного курсора. Чат и просмотр можно проверять локально; управление — на двух компьютерах. При ошибке определения адресов управление не включается.
