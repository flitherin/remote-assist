# Remote Assist: начальный каркас

Это локальная демонстрация интерфейса на C для Windows 10/11 x64, а не работающая система удалённого администрирования. Два EXE показывают интерфейс подтверждения и остановки. Сетевого подключения, захвата экрана, передачи команд и удалённого ввода нет. FreeRDP не включён и не подключён.

## Сборка Windows

Установите Visual Studio 2022 Build Tools с компонентами C++ и Windows SDK, а также CMake. В Developer Command Prompt выполните из папки проекта:

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Результаты: `build/Release/assist_client.exe`, `assist_server.exe`, `assist_session.lib`. Используется статическая CRT MSVC `/MT`. Системная библиотека Windows `user32.lib` является импортной: системные DLL остаются необходимыми.

## Интерфейс для ассемблера

В `include/assist_session.h` доступны `assist_confirm_local`, `assist_stop_local`, `assist_is_confirmed`. Они изменяют только локальный флаг интерфейса; флаг не является аутентификацией или разрешением удалённому участнику. Вызовы должны выполняться в одном потоке. Для MASM x64 используйте Windows x64 ABI, 32 байта shadow space и корректное выравнивание стека.

## Требования к будущей реализации

Нужны проверка личности обеих сторон и сертификатов, локальное согласие на конкретного участника, разделение просмотра и управления, постоянная индикация сеанса, отзыв доступа, журнал событий и обработка разрыва связи. Для Windows отдельно проверяются несколько мониторов, DPI, блокировка сеанса, UAC и защищённый рабочий стол.

FreeRDP имеет C API и Apache-2.0: https://github.com/FreeRDP/FreeRDP . Статическая сборка требует проверки всех зависимостей. Эта заготовка не подтверждает совместимость серверной реализации FreeRDP с Windows 10/11.

## Проверка

На Linux можно собрать только переносимую библиотеку: `cmake -S . -B build-portable`, затем `cmake --build build-portable`. GUI и конечные Windows EXE нужно собрать и проверить на Windows.

## Готовая сборка 13.10.2026

В dist находятся два PE32+ GUI EXE для x64 и архив RemoteAssist-demo-win64.zip. Собраны MinGW GCC 14 с оптимизацией, ASLR/DEP и статической линковкой библиотек toolchain. Импортируются только системные COMCTL32, GDI32, KERNEL32, msvcrt и USER32. Эта MinGW-сборка использует системную msvcrt.dll; /MT применяется к сборке MSVC.

Манифест встроен в EXE: asInvoker, uiAccess=false, Common Controls v6, совместимость Windows 10/11 и PerMonitorV2. Добавлена информация о версии. Интерфейс на русском, белый фон и Segoe UI. Доступна навигация Tab. Цифровой подписи нет; манифест не заменяет подпись и не гарантирует отсутствие предупреждений SmartScreen.

Проверены компиляция с -Wall -Wextra -Werror, архитектура, таблица импорта, наличие встроенного манифеста и корректность его XML. Запуск и визуальная проверка на Windows 10/11 ещё не выполнены. Сборка воспроизводится скриптом build_windows.py при наличии локального toolchain в .toolchain.

Обновление интерфейса: раздельные заголовки ролей, адрес только для чтения, поле порта и явное обозначение отсутствия транспорта. EXE и архив пересобраны; визуальная проверка на Windows не выполнена.
