# Просмотр экрана
Экран встроен в основное окно RemoteAssist.exe. Кадры 1280×720 со сжатием XPRESS Huffman без потерь; до четырёх кадров в секунду при свободной очереди. Основной монитор, пропорции сохраняются с полями. Владелец отдельно подтверждает показ. Остановка передаёт SCREEN_STOP после уже отправляемого кадра; изображение у оператора очищается. Завершение соединения очищает изображение. Встроенное управление доступно после отдельного подтверждения владельца. Транспорт без шифрования. При проверке двумя экземплярами на одном ПК возникает рекурсивный захват.

Управление реализовано в новой версии CHAT/3, см. README.md. Отдельное разрешение владельца обязательно; остановка показа отзывает управление.
